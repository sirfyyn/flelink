Run Qwen3.8-Flash-Next locally on one GPU

Qwen3.8-Flash-Next is a mixture-of-experts model with 125 billion parameters. The FLE quant (FLE-IQ3_M) is an 88.9 GB file, far more than a graphics card holds. The FLE engine keeps the experts in RAM and the busiest ones on the GPU, so the model runs from a 16 GB card and 64 GB of RAM.

flelink run fle-iq3-m

What you need

One NVIDIA card from 16 GB and 64 GB of RAM; the top speed was measured with 32 GB and 128 GB of RAM.

"no engine": this recipe needs the FLE engine, which has an NVIDIA CUDA build only. File size 83 GiB including the draft model.

The verdicts are the rule FLE Link applies before it downloads anything (the rules in full). A speed is shown only for the hardware it was measured on. A size nobody measured yet? flelink bench --task pagoda --share posts yours to the benchmarks board.

Good to know

  • On the same file and the same 32 GB card the FLE engine decoded at 91 tokens/s, Strata at 74 and llama.cpp at 36 (median over six tasks, 6 Oct 2026).
  • The 91 tokens/s were measured with the engine's MTP draft head started by hand; flelink run starts the model without the head so far.
