Run Llama 3.2 1B locally on any laptop

Llama 3.2 1B Instruct is the smallest model in the catalog: a 0.8 GiB file that runs on any laptop, with or without a GPU. It is the model of the first-run recording on the main page: 68 seconds from an empty home folder to the first answer.

flelink run llama-3.2-1b

What you need

Any machine: macOS, Linux or Windows, no GPU required.
