Run DeepSeek V4.1 Flash locally on one 32 GB GPU

DeepSeek V4.1 Flash is a mixture-of-experts model with 763 billion parameters. As a 2-bit GGUF it is 232 GiB, seven times the memory of a 32 GB card. FLE Link runs it anyway: the FLE engine keeps the experts in RAM, puts the busiest ones on the GPU and lets a small draft model (DSpark) propose tokens that the big model checks.

flelink run deepseek-v41-ista-dspark
flelink run rin-deepseek-v41-dspark

What you need

One NVIDIA card with 32 GB, 120 GB of RAM and about 260 GB on a fast NVMe. FLE Link installs the FLE engine (v1.2.5 or newer) by itself.

The verdicts are the rule FLE Link applies before it downloads anything (the rules in full). A speed is shown only for the hardware it was measured on. A size nobody measured yet? flelink bench --task pagoda --share posts yours to the benchmarks board.

Good to know

  • The recipe deepseek-v41-ista-dspark uses ISTA DASLab's GSQ-RCO quant (IQ2_XXS) with the DSpark draft model. The draft does not change the answer: the model checks every drafted token.
  • Rin (rin-deepseek-v41-dspark) is the same model split into a hot half that stays on the GPU and a cold half served from RAM. It is a little faster and a little worse than the quant it is made from; the model card has the numbers.
  • The 2-bit quant itself is lossy: its next token agrees with the original weights 83.5 to 85.2 % of the time.
