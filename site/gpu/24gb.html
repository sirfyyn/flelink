What runs on a 24 GB GPU: local AI models that fit

A 24 GB NVIDIA card runs more than its memory suggests. For mixture-of-experts models the FLE engine keeps the experts in RAM and only the busiest ones on the GPU, so the RAM decides which model fits. With 128 GB of RAM the biggest model in the catalog that fits a 24 GB card is Qwen3.8-Flash-Next.

The verdicts are the rule FLE Link applies before it downloads anything (the rules in full). A speed is shown only for the hardware it was measured on. A size nobody measured yet? flelink bench --task pagoda --share posts yours to the benchmarks board.

Other sizes: 12 GB · 16 GB · 32 GB. Any other GGUF file works with flelink run /path/to/model.gguf; the calculator on the main page takes any size, an Apple Silicon Mac or no GPU.
