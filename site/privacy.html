This website

The site is static: no cookies, no analytics or advertising services, no external fonts, nothing loaded from third parties. It runs on my own server at Hetzner Online GmbH in Nuremberg, Germany. The web server logs each request (host name, IP address, time, request, status, size, user agent, referrer); the logs are rotated daily and deleted after 14 days. They serve safe operation and a daily count of page views, which keeps no IP addresses and no user agents. The install script comes from this server; the program itself is downloaded from GitHub Releases.

The program FLE Link

FLE Link runs on your own computer and sends nothing to me. It connects only to the services you use: GitHub (engine downloads and checksums), Hugging Face (model downloads), a search service if you switch on web search, and the accounts you connect yourself (below).

Google user data

When you connect your Google account under Settings > Accounts, FLE Link asks Google for read access to your calendar events. This is what happens with that data:

  • What is accessed: the events of your primary Google Calendar from one week back to 90 days ahead: title, description, location, start and end. Nothing else from your Google account.
  • How it is used: only to show your calendar on the Agent page of FLE Link and to let the agent that runs on your computer take your appointments into account. FLE Link reads them again every five minutes.
  • Where it is stored: on your computer only. The events are kept in the agent's local database file, the sign-in token in a file that only your user account can read. No copy goes to me or to any server of mine; FLE Link has none.
  • Sharing: FLE Link does not share, sell or transfer Google user data. The events are given only to the language model you run with FLE Link. If you point FLE Link at a model or tool on another computer yourself, the agent's input, which can contain your appointments, goes there; FLE Link does not do that on its own.
  • No advertising, no training: Google user data is not used for advertising, not used to train or improve AI models, and not read by any person.
  • Deletion: Disconnect in Settings > Accounts. FLE Link then revokes the token at Google, deletes it, and removes the mirrored events from the agent. You can also remove the access at any time at myaccount.google.com/permissions.

FLE Link's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

iCloud calendars

If you connect iCloud under Settings > Accounts with an app-specific password from Apple, the same holds for your iCloud calendars: FLE Link reads the events of all your calendars in the same window, keeps them on your computer for the Agent page and the agent, shares them with no one and removes them when you disconnect. The Apple ID and the app-specific password stay in a file only your user account can read and go only to Apple's calendar server. You can revoke the password at any time at account.apple.com.
